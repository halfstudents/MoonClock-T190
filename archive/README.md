# Earlier code and source snippets

These files preserve the development history. Use `firmware/MoonClock_T190` for the latest complete sketch from the conversation.

- `Serial_Clock`: earlier Wi-Fi/time version with no complete TFT interface.
- `Static_Display`: earlier graphical version, before the dedicated SPI correction.
- `code-blocks`: every unique code block in the shared conversation's assistant text, in conversation order. These are `.txt` files because many are fragments, configuration examples, or replacements rather than standalone sketches. `index.json` maps each block to the zero-based message position and records its SHA-256 digest.

Historical examples may contain superseded display initialization. Do not combine sketches or upload fragments as standalone programs.
